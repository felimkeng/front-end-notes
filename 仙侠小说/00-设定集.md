# 《拾薪录》设定集

> 柴要一根根拾，火要一点点添。
> ——陈拾

## 一、书名与主题

**《拾薪录》**

"薪"有两层意思：

1. 凡人视角的"薪"：捡柴度日的贫寒。主角出身南荒最穷的山村，一根柴、一株药、一粒灵砂，都要靠双手一点点攒。修行对他而言从来不是天降神通，而是攒够了柴才敢生一把火。
2. 天地视角的"薪"：薪火照天。上古有人以自身为薪点亮天路，接引后人成仙；天路断绝之后，火种散落。主角拾到的那一截灯芯，便是当年的余火。

全书终极命题：**仙路已断三万年，这一世还能不能重新点亮天路？点亮之后，是自己渡过去，还是留给后来者？**

三种气质的融合方式：

| 来源 | 借用的骨架 | 在本书中的落点 |
|---|---|---|
| 凡人流 | 明确的境界体系；资源驱动；主角资质平庸靠心性与算计；每一步都要"攒"；能苟则苟 | 陈拾的行事方式与卷一至卷三的主叙事节奏 |
| 遮天式 | 万古时间尺度；古皇/古仙遗迹；禁区与不死存在；"成仙路"作为终极悬念 | 世界背景、卷三以后逐渐展开的宏大主线 |
| 玄鉴仙族式 | 灵气稀薄；寿元短；破境即死；丹药有毒；修士对凡人的压迫真实可感 | 所有境界数值、灵税制度、药奴制度、主角的每一次突破 |

## 二、世界地理

### 2.1 总格局

天地分为**神州**与**四荒**。

- **神州**：位于天地中央的大陆。上古天倾之劫后，仙域碎裂坠落，其中最大的一块便是神州。灵脉纵横，灵气浓郁，古皇遗迹与禁区遍布。当世所有合体、炼虚大修士几乎都在神州。
- **四荒**：环绕神州的四片贫瘠之地——东溟、西漠、北原、南荒。四荒与神州之间隔着**归墟海**，凡人绝无可能渡过，筑基修士渡海亦十死其九。
- **南荒**：四荒中最贫的一荒。灵气稀薄到几乎无法自然引气，山多、瘠、毒瘴重。南荒之中又以**黔州**最偏。

### 2.2 黔州

黔州是南荒西南角一片群山围合的盆地，方圆约三千里，凡人王朝**青芜国**统治，人口不足千万。

黔州灵气极薄，整个黔州只有三条勉强能称为"灵脉"的地脉，分别被三家宗门占据：

| 宗门 | 所据灵脉 | 立身之本 | 当家境界 |
|---|---|---|---|
| **青苓宗** | 青苓山 | 丹药、灵药。控制黔州几乎所有药材来源与灵税征收 | 宗主结丹初期（黔州唯一的结丹修士，已两百七十余岁） |
| **赤崖门** | 赤崖 | 炼器、矿脉。风格粗野，弟子多出身矿奴 | 门主筑基后期 |
| **幽篁谷** | 幽篁涧 | 阵法、符箓。人最少，最阴 | 谷主筑基后期 |

三宗表面共治，实则青苓宗一家独大。三宗合计筑基修士不足三十人，炼气修士约两千。整个黔州千万人口，能修行者万中无一。

### 2.3 苦竹县与柴沟村

主角出生地。

- **苦竹县**：青芜国西境的一个穷县，靠山吃山。县城里有青苓宗设的**药行**，专门收凡人采来的灵药，也是灵税的征收点。县令姓魏，凡人，对宗门低眉顺眼，对百姓凶如虎狼。
- **柴沟村**：苦竹县西面的山村，四十几户，靠采药、烧炭、砍柴为生。村后是**断碑崖**——一片瘴气弥漫、常有人失踪的古山，山中有上古坍塌的石殿残迹。村人只敢在崖前浅山采药，从不深入。

## 三、境界体系与寿元

### 3.1 境界

```
凡人 → 炼气（一至九层）→ 筑基 → 结丹 → 化神 → 炼虚 → 合体 → 【仙路已断】
```

| 境界 | 寿元上限 | 黔州现状 | 突破难点 |
|---|---|---|---|
| 凡人 | 六十至七十 | 千万 | — |
| 炼气 | 约一百二十 | 约两千人 | 需有灵根；南荒灵气稀薄，无功法辅助者一生难引气入体。层与层之间靠积累，无捷径 |
| 筑基 | 约二百 | 不足三十人 | 必须服**筑基丹**辅助，否则十死无生。筑基丹主药"地元芝"黔州百年才出数株，几乎被青苓宗垄断。有丹辅助者成功率也不到三成，失败即经脉尽毁 |
| 结丹 | 约五百 | 一人 | 需在筑基后期凝聚假丹、再化真丹。黔州千年出过五个结丹修士 |
| 化神 | 约一千五百 | 无 | 南荒全境不过寥寥数人。需要天地灵气充沛之地，南荒几乎不可能 |
| 炼虚 | 约五千 | 无 | 神州大宗底蕴。多为古老宗门的太上长老 |
| 合体 | 约一万 | 无 | 当世顶点。合体之后再无前路，寿尽即死。神州现存合体修士不知确数，多数自封或隐入禁区 |
| 渡劫 / 成仙 | — | — | 上古有之。三万年前天倾之劫后，再无一人成仙。这是全书最大的悬念 |

### 3.2 寿元劫

寿元是本书最大的压迫来源。

- 每一境界的寿元上限并非"活到那时死"，而是过了大约八成之后，身体开始衰败，修为渐退。炼气修士活到百岁便已老朽如凡人。
- 突破失败不但伤根基，还会**折寿**。炼气冲筑基失败者，若侥幸活下，寿元多半只剩数年。
- 因此"要不要赌这一次突破"，是每个修士一生中最凶险的选择。很多人宁愿在炼气九层老死，也不敢碰筑基丹。

### 3.3 灵根

灵根决定能否引气以及引气快慢。本书不用"天灵根、伪灵根"那种明确的等级，只用**清浊**与**偏全**两个模糊的维度描述：

- **清浊**：灵根越清，引气越快，杂质越少。浊灵根引气极慢，一日所得不及清灵根的十分之一。
- **偏全**：偏某一属性者，修该属性功法事半功倍，修其他功法举步维艰。

陈拾的灵根：**浊、偏火**。青苓宗测灵的说法是"浊得像烧过的柴灰，勉强有一点火性"。引气极慢，但奇稳，且对火性丹毒的耐受远高于常人——这一点直到卷二他才自己发现。

### 3.4 丹毒

丹药是修行的加速器，也是慢性毒药。

- 任何丹药服下，都会在经脉与脏腑中留下**丹毒**。丹毒累积到一定程度，经脉阴蚀、真气浊滞、寿元折损。
- 洗涤丹毒需要天材地宝或极高明的丹师，穷修士根本负担不起。
- 于是有个残酷的规律：**富家子弟靠丹速升而早夭，穷苦修士慢而稳却往往来不及**。陈拾一生都在这条规律中间找那条窄路。

### 3.5 货币与物价

- **凡人**：铜钱、银两。柴沟村一户人家一年花销约十两银。
- **修士**：**灵砂**（碎灵石）为黔州通用货币，一百粒灵砂约合一块**下品灵石**。黔州一块下品灵石约值百两银——是凡人一家十年的花销。
- 一株普通灵药（如三十年"赤茸"）在药行收价约五到二十粒灵砂；一颗最下等的"引气散"卖三十粒灵砂；一颗筑基丹在黔州有价无市，传闻上一次交易是两千块下品灵石加一条矿脉。

## 四、核心设定：古灯芯

### 4.1 外形

一截三寸长、色如枯骨的灯芯，触手温凉，凡火不能点燃，刀斧不能断，浸水不湿。陈拾在断碑崖坍塌的石殿深处捡到，当时它插在一座已经碎裂的青石灯盏里。

### 4.2 点燃的代价

灯芯只认一种"薪"：**活人的精血与寿元**。

- 以指血涂抹灯芯，默念不出，只需"想它亮"，灯芯便燃起一簇青白色的火苗，无烟，不热，风吹不动。
- **每燃一息，折寿数刻；燃满一刻钟，折寿约三日。** 燃灯时人会感到骨头里冷、心跳变慢，像有人在抽自己的命。灯芯燃得越久，抽得越凶，不成正比而是加倍。
- 这个代价迫使陈拾把每一次点燃都当作"押命"。整个卷一到卷三，他点燃灯芯的总次数不超过十次。

### 4.3 三种用处（逐卷解锁）

| 用处 | 解锁时机 | 效果 |
|---|---|---|
| **照** | 卷一 | 火光照到之处，灵气流动、灵药所在、隐匿之物、禁制的薄弱处，全部无所遁形。这是陈拾早期最重要的"金手指"：他能在别人看不到灵药的地方看到灵药 |
| **镇** | 卷二 | 火光所及，阴邪、鬼物、被丹毒侵蚀过深的修士，会本能地退避与畏惧 |
| **焚** | 卷四 | 灯火可焚毁禁制、神识印记、乃至某些"不该存在的东西"。代价极重 |

### 4.4 燃灯所见

每一次点燃，陈拾都会在火光深处看见一些零碎的画面：一座通天的巨灯，灯下无数人影排队向上走；一个背影伸手把自己的心口剖开，往灯里添了什么；天裂开。

这些画面是全书宏大线的伏笔。他起初以为是幻觉，到卷三才逐渐拼凑。

### 4.5 真相（作者备忘，正文中逐步揭示）

- 上古时代，成仙并非无路。天地之间有一座**天路灯**，由被称为"**照天者**"的修士世代守护。渡劫修士需在灯下受火照身，洗尽尘垢，方能踏上天路。
- 三万年前**天倾之劫**：天路灯被毁。谁毁的、为什么毁，是卷四、卷五的核心谜题（初步设定：一部分合体修士不愿后人越过自己，联合禁区中的某些存在扑灭了天灯；最后一任照天者以自身为薪，保下一截灯芯）。
- 灯芯散落四荒。陈拾拾到的是其中之一，也可能是唯一。
- 卷六的最终选择：灯芯重燃天路，只够照一人渡过。陈拾要么自己成仙，要么留下火种让后人得渡——"薪尽火传"。

## 五、势力与人物

### 5.1 青苓宗（卷一至卷二主要对手/环境）

- 黔州霸主，以丹药立宗。掌控灵药来源，通过青芜国王朝代征**灵税**。
- **灵税**：青芜国每户凡人每年需缴纳一定数量的灵药，或以银两、劳役折抵。凑不出的人家，可以用**有灵根的孩子**折抵，或者被征为**药奴**。
- **药奴**：被征入宗门的凡人，用于深山采药、试药、看炉。深山采药死于毒瘴与野兽者过半；试药者更少有活过三年。
- **主要人物**：
  - **宗主** 苓虚子：结丹初期，二百七十余岁，寿元将尽，急于寻找延寿之法。卷二幕后，卷三初的最大威胁。
  - **外门执事** 程九：炼气七层，五十余岁，苦竹县药行的实际掌控者。贪、精、不蠢，深知自己此生无望筑基，只想多攒灵砂。陈拾早期最直接的压迫者，也是最早察觉他"找药总比别人准"的人。
  - **外门弟子** 韦娓：炼气三层，二十岁，程九的远房外甥女，负责药行验药。冷淡、公事公办，是卷一少数没有把凡人当牲口看的修士。卷二会有交集。

### 5.2 青芜国（凡人王朝）

- 依附青苓宗而存，代收灵税，负责镇压凡人。
- **苦竹县县令** 魏澄：凡人，五十岁，善于逢迎。灵税加征时，他是执行者。
- **县衙差役头目** 郑蛮：凡人武夫，打人的手。

### 5.3 柴沟村（卷一背景）

- **陈老根**：陈拾的父亲，四十五岁，采药人。手上满是药汁染的黄褐色，认识两百多种药，从不敢进断碑崖深处。老实、木讷、拼命。卷一死亡。
- **陈拾的母亲**：陈拾七岁时病死，家中无钱买药。这是陈拾对"修士"最早的认识：药行里有能救命的药，但凡人买不到。
- **太爷爷**：陈拾从未见过。曾是青苓宗杂役弟子，炼气二层老死，被逐出宗门前抄了一份残缺的引气功法《引气篇》，只到炼气三层，藏在家中土墙里。家里没人识字，只当作是祖上留下的护符。
- **顾先生**：村里唯一识字的人，破落塾师，六十岁。教过陈拾认字。会在卷一的关键处帮陈拾读懂《引气篇》，卷一末死于灵税之乱。
- **胡三**：村里另一个采药人，比陈老根胆大贪心，灵税加征后第一个去断碑崖深处的人。

### 5.4 神州（卷三起）

- **十二古宗**：神州十二个古老传承，多数由上古古皇、古仙的道统延续而来。各有一件"仙路已断"之前的遗物镇宗。
- **禁区**：神州散布着七处禁区——如**坠仙渊**（据说是一位渡劫者坠落之地）、**不周残柱**（天倾之劫的残迹）、**万古坟场**（葬着不知多少上古大修士，也养着以吞噬寿元苟活的"不死者"）。
- **不死者**：天倾之劫的幸存者，寿元早尽，全靠禁区中的古老手段吞噬他人寿元续命。它们等待天路重开的那一天，也决不允许别人先于自己渡过去。

## 六、主角

### 陈拾

- **开篇年龄**：十四岁。
- **外形**：瘦，个子矮，手上有柴刀留下的老茧。一双眼睛总是在看东西的"值不值"。
- **性格**：
  - 寡言。穷人家孩子说多了没用。
  - **算得极细**。这是穷出来的本事：一斤柴多少钱，一株药值几个铜板，走哪条山路能少费半个时辰。修行之后，这套算法直接迁移到灵砂、丹毒、寿元上。
  - **不贪、不赌**。他见过村里贪心的人怎么死在山里。
  - **但真到必须赌的时候，敢押命**。他的判断标准不是"能不能赢"，而是"不赌是不是一定死"。
- **修行方式**：浊火灵根，引气极慢。他的所有突破都不靠资质，靠三样东西：慢慢攒来的资源、灯芯"照"出来的别人看不见的机会、和赌命时算得比别人清楚。
- **底线**：不吃人（不吞噬他人寿元）。这条底线在卷五会被逼到极限。
- **成长弧线**：
  - 卷一：从"修士是神明"到"修士也是人，只是比我多活一百年"。
  - 卷二至卷三：从"我要活下去"到"我要看看这天上到底有什么"。
  - 卷四至卷六：从"我要成仙"到"要不要有人成仙"。

## 七、写作风格备忘

- 叙事视角：第三人称限制视角，紧贴陈拾。他不知道的事，读者也不知道。
- 语言：白描为主，少用成语堆砌。修士出场时可以写得高远，凡人视角写得沉重贴地。
- 节奏：凡人流式的慢热。卷一大部分篇幅在凡间，让读者先感受"凡人有多难"，再感受"修士有多难"。
- 战斗：不写光效。炼气修士打架和凡人打架的区别只在于"快一点、硬一点、能用几张符"。真正的高境界战斗要到卷三之后。
- 忌：忌主角开挂无脑碾压；忌灯芯变成万能钥匙；忌配角智商下线。所有对手都在按自己的利益认真行动。
